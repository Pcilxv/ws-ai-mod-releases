# 江湖传音

《逸剑风云决》AI 对话模组的公开发行与更新仓库。

- 与角色自由聊天、远程传音，支持 2–4 位 NPC 群聊。
- 保存聊天记忆，结合已记录的剧情见闻；支持确认后的物品交接。
- 在游戏中管理 AI 接口方案、测试连接、检查模组更新。

## 下载与使用

从 [最新正式版](https://github.com/Pcilxv/ws-ai-mod-releases/releases/latest) 下载完整 ZIP 并解压。
先安装兼容的 UE4SS，再退出游戏运行 `Install.cmd`。进入游戏后在“AI 接口”填写自己的服务配置，按 F7 或点击“聊天”开始使用。

详细功能和操作见包内《功能简介.md》《使用说明.md》。需要 Windows 10/11 64 位；无需另外安装 Python。AI 回复不保证准确，服务费用由玩家选择的提供商决定。

## 更新与卸载

支持更新的版本可从“AI 接口 → 模组更新”检查并下载，保存退出游戏后安装。更新会保留配置与聊天并备份旧版。

卸载请退出游戏，运行完整解压包中的 `Uninstall.cmd`，按提示选择保留或删除个人资料。不删除游戏存档、其他模组或 UE4SS。

仅在此仓库发布必要说明与发行附件；不要上传 API 密钥、配置、聊天记录或个人备份。
