# 江湖传音 · 发行与更新

《逸剑风云决》AI 对话模组的公开发行仓库。这里仅维护版本说明和发行包；不包含私有开发历史、玩家配置或聊天记录。

到 [Releases](https://github.com/Pcilxv/ws-ai-mod-releases/releases) 下载完整发行包，解压后运行 Install.cmd。需要兼容 UE4SS，安装包不替换 UE4SS 和其他模组。

1.1.0 起可在游戏的 AI 接口 → 模组更新中检查新版本，确认下载后保存并退出游戏，后台完成安装。旧版玩家需手动安装一次。

卸载：退出游戏后运行解压包内 Uninstall.cmd，可保留配置与聊天，或彻底移除个人资料。历史备份逐项确认删除。

模组仍处于持续维护中。模型回复不保证完全准确；安装与更新均保留本地备份。请勿上传 API 密钥或个人聊天。
